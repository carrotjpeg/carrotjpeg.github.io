cs 61c cpu
project page

Designed and implemented a 32-bit RISC-V CPU in Logisim Evolution over the course of a month, starting from a single-cycle datapath and extending it into a 2-stage pipelined processor capable of running the full RV32I instruction subset covered in CS 61C.

Built the core datapath blocks from scratch — program counter, register file interface, immediate generator, branch comparator, ALU control, and partial load/store logic — then wired the control signals so every R, I, S, B, U, and J-type instruction produced correct architectural state after each clock edge.

Extended the design into a two-stage pipeline by splitting fetch from execute/memory/writeback, adding pipeline registers for PC and instruction, and resolving control and data hazards with branch flushing and forwarding from the writeback path.

Verified the CPU against the staff test suite and a set of custom RISC-V programs, including recursive function calls, memory-mapped I/O, and a small benchmark — all passing in simulation. CPU image not fully pictured.
